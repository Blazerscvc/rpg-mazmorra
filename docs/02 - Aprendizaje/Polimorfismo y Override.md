# Polimorfismo y Override

**Estado:** Concepto aplicado.

Una referencia Weapon puede apuntar a un objeto SpecialWeapon. Al invocar setName(), se ejecuta el método sobrescrito de la subclase. @Override permite al compilador comprobar que existe el método correspondiente en la jerarquía. No implica cambiar todos los métodos heredados.

**Fuente:** `rpg/items/SpecialWeapon.java`.
