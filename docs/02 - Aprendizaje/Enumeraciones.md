# Enumeraciones

**Estado:** Concepto aplicado.

Un enum define constantes tipadas y restringe categorías a un conjunto conocido. TypeWeapon categoriza armas, Team representa bandos y CombatState define estados. Una referencia enum puede ser null: los argumentos obligatorios deben validarse. El enum describe estados, no aplica por sí mismo las transiciones.

**Fuente:** `rpg/combat/CombatState.java; rpg/entities/Team.java; rpg/items/TypeWeapon.java`.
