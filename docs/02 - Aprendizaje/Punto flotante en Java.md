# Punto flotante en Java

**Estado:** Concepto aplicado.

double utiliza representación binaria; muchos decimales no se almacenan de forma exacta. EPSILON permite tratar resultados próximos a cero según las reglas del dominio. Double.isFinite excluye NaN e infinitos; Double.isNaN detecta NaN. Weapon permite durabilidad infinita positiva pero no daño infinito. Formatear dos decimales no modifica el valor interno.

**Fuente:** `rpg/entities/Entity.java; rpg/items/Weapon.java`.
