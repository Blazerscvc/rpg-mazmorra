# Herencia y clases abstractas

**Estado:** Concepto aplicado.

Una clase abstracta no se puede instanciar directamente; puede proporcionar atributos y métodos compartidos. `extends` expresa herencia y `super(...)` invoca el constructor de la clase padre. Combatant reutiliza salud, resistencia, daño y curación de Entity. SpecialWeapon reutiliza Weapon y cambia ciertas reglas. Una clase abstracta no necesita métodos abstractos.

**Fuente:** `rpg/entities/Entity.java; Combatant.java; rpg/items/SpecialWeapon.java`.
