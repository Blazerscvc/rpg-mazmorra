# Separación de presentación y motor

**Estado:** Decisión adoptada; implementación pendiente.

El motor debe producir datos de combate independientes de cómo se presentan. La consola y la futura interfaz JavaFX podrán consumirlos. El mecanismo concreto todavía no está decidido: se comenzará por diseñar un objeto de evento de ataque.

Ver [[Registro de combate]], [[Arquitectura del RPG]] y [[Decisiones técnicas]].
