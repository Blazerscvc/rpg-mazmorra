# RPG Mazmorra

Proyecto personal de desarrollo de un RPG de mazmorras y exploración, programado en Java.

El objetivo principal es practicar programación orientada a objetos (POO), aplicar buenas prácticas de desarrollo y ampliar progresivamente el juego conforme adquiero nuevos conocimientos.

## Tecnologías

- Java
- Maven
- IntelliJ IDEA
- Git y GitHub

## Funcionalidades implementadas

- Sistema básico de entidades con vida y resistencia.
- Personajes con estadísticas de combate.
- Armas con distintos tipos y requisitos de fuerza.
- Equipamiento básico de armas.
- Sistema de durabilidad y reparación.
- Fragmentación permanente de armas con penalización de daño.
- Armas especiales con durabilidad infinita y nombres protegidos.

## Funcionalidades previstas

- Combate automático por equipos.
- Exploración de mazmorras.
- Inventario y equipamiento.
- Enemigos con distintos comportamientos.
- Sistema de niveles y habilidades.
- Botín y mejoras de equipo.
- Guardado y carga de partidas.

## Estado del proyecto

**En desarrollo — MVP inicial.**

Actualmente se está construyendo la base de entidades, armas y personajes. Las funcionalidades se implementan y prueban progresivamente.

## Propósito

Este proyecto es una iniciativa personal de aprendizaje, no una entrega académica. Su desarrollo se centra en comprender los principios de la programación orientada a objetos y aplicar nuevos conceptos de forma práctica.
